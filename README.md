# V-Track: Vehicle Reservation and Management System

# 1. Project Title

V-Track: Vehicle Reservation and Management System

# 2. Project Description

V-Track is a web-based vehicle reservation and management system designed to make vehicle booking and fleet management more organized and convenient. It allows users to browse available vehicles, make reservations, and manage their booking information. It also provides administrative functions for managing vehicle records and monitoring reservations.

# 3. Problem Being Addressed

Managing vehicle reservations manually can be time-consuming and may lead to problems such as scheduling conflicts, difficulty tracking vehicle availability, and disorganized reservation records.

V-Track aims to address these problems by providing a centralized system where users can view vehicles and make reservations while administrators can manage vehicle information and reservation records.

# 4. Project Objectives

The main objectives of V-Track are:

- To provide an organized platform for browsing available vehicles.
- To allow users to make and manage vehicle reservations.
- To help administrators manage vehicle information and reservation records.
- To make the reservation process more convenient and accessible.
- To reduce the difficulties associated with manual vehicle reservation management.

# 5. Target Users

The system is intended for:

- **Customers/Users:** Individuals who want to browse vehicles and make reservations.
- **Administrators:** Authorized users responsible for managing vehicle information and monitoring reservations.

# 6. Main Features

V-Track includes the following features:

- **User Login and Registration:** Allows users to access the system through their accounts.
- **Vehicle Fleet:** Displays the available vehicles and their information.
- **Vehicle Search and Filtering:** Helps users find vehicles based on available search and filter options.
- **Vehicle Reservation:** Allows users to make vehicle bookings.
- **Reservation History:** Displays users' reservation records.
- **Admin Dashboard:** Provides administrative access to system management features.
- **Vehicle Management:** Allows administrators to add, update, and manage vehicle records.
- **Reservation Management:** Helps administrators monitor and manage reservations.
- **Booking Modal:** Provides an interface for entering reservation details.
- **Printable Authorization Form:** Allows relevant reservation information to be printed.

# 7. Technologies Used

The project uses the following technologies:

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used for the visual design, layout, and animations.
- **JavaScript** – Used to implement system functions and user interactions.
- **Tailwind CSS** – Used through its CDN for interface styling.
- **Font Awesome** – Used for icons and visual elements.
- **Browser Local Storage** – Used to store system information locally in the browser.

# 9. OOP Concepts Demonstrated

The current web implementation is written in JavaScript and uses objects to organize information such as vehicle and reservation records, along with functions to handle system operations.

The four fundamental OOP principles are:

- **Encapsulation:** Organizing related data and operations together within a class.
- **Inheritance:** Allowing one class to acquire properties and methods from another class.
- **Polymorphism:** Allowing different classes to implement the same method in different ways.
- **Abstraction:** Hiding unnecessary implementation details and presenting essential functions to users.

# 10. Instructions for Running the Program

1. Download or clone the V-Track repository from GitHub.
2. Open the downloaded project folder.
3. Locate the `src` folder.
4. Make sure the following files are present:
   - `index.html`
   - `style.css`
   - `script.js`
   - `login.js`
5. Open `index.html` using a web browser.
6. Make sure you have an internet connection because the project uses external CDN resources for some interface components.


# 12. Known Limitations

- The system currently operates as a browser-based application.
- System information is stored locally in the browser rather than in a centralized online database.
- Data stored in browser Local Storage is limited to the browser and device being used.
- The current authentication implementation uses client-side JavaScript and is not suitable for secure production authentication.
- The system requires an internet connection for externally hosted interface resources.

# 13. Future Improvements

Possible improvements for future versions include:

- Implementing a centralized database for storing vehicle and reservation records.
- Adding stronger authentication and account security.
- Developing a responsive mobile version.
- Adding online payment integration.
- Adding email or SMS reservation notifications.
- Improving administrative reporting and reservation monitoring.
